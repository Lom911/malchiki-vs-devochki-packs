# Наборы вопросов для «Мальчики против девочек»

Здесь лежат наборы вопросов для приложения «Мальчики против девочек» (Android). Приложение заходит сюда только тогда, когда игрок сам нажал в настройках «Загрузить новые вопросы»: берёт `catalog.json` и по нему файлы новых наборов. В запросе только адрес файла и название приложения, личные данные не передаются.

## Что здесь лежит

- `catalog.json` — список наборов: название, файл, размер и контрольная сумма SHA-256 каждого файла.
- `packs/` — файлы наборов (`p2.json`, `p3.json` и так далее): в каждом 40 вопросов для мальчиков и 40 для девочек.
- `images/` — фото к вопросам; папка появляется с первым набором, в котором есть фото.

## Правила

- **Файлы создаются инструментами игры, руками их не правят.** Приложение сверяет размер и SHA-256 каждого скачанного файла с каталогом и отклоняет набор, если отличается хотя бы один байт.
- **Опубликованный набор и его фото окончательные.** Приложение ставит только те наборы, которых у игрока ещё нет, и уже установленный набор не заменяет. Поэтому исправление выходит новым набором с новым номером, а не правкой старого; набор вычитывают до публикации.
- **Фото** берут с бесплатных фотостоков Pexels и Unsplash; автор и ссылка записаны в самом наборе (поле `imageCredit` у вопроса).
