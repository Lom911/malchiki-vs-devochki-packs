# Политика конфиденциальности приложения «Мальчики против девочек»

Действует с 3 ноября 2026 года. Относится к приложению «Мальчики против девочек» для Android (идентификатор `ru.malchikivsdevochki.game`), версия 1.0.0 и новее.

## Коротко

Приложение **ничего не собирает** о вас и **не отправляет** никаких ваших данных. Играть можно без интернета. В сеть приложение выходит только тогда, когда вы сами нажали в настройках «Загрузить новые вопросы»: оно скачивает файлы с новыми вопросами из GitHub (запасной вариант — jsDelivr). Всё, что приложение помнит, остаётся только на вашем телефоне.

## Какие данные мы собираем

Никакие. Приложение не собирает, не получает и не отправляет:

- персональные данные (имя, телефон, почту, адрес, фото, контакты);
- данные об устройстве и рекламный идентификатор;
- местоположение;
- данные об использовании: статистику, отчёты об ошибках, аналитику.

У разработчика нет своего сервера, на который приложение что-то присылало бы. В приложении нет регистрации и аккаунтов, нет рекламы, нет сторонних SDK для аналитики или рекламы и нет покупок.

## Доступ в интернет и разрешения

У приложения есть одно разрешение: доступ в интернет. Оно нужно только для кнопки «Загрузить новые вопросы» в настройках.

- Приложение выходит в сеть **только после нажатия этой кнопки**. При запуске и во время партии оно в интернет не обращается, фоновых проверок и уведомлений нет.
- По нажатию приложение скачивает файлы: список наборов вопросов, сами наборы и фото к ним. Файлы берутся из публичного репозитория на GitHub (`raw.githubusercontent.com`), а если он недоступен, с зеркала jsDelivr (`cdn.jsdelivr.net`). Соединение защищённое (HTTPS), каждый файл проверяется по контрольной сумме.
- Приложение только получает эти файлы. **Личные данные не передаются**: ни имя, ни названия команд, ни настройки, ни история вопросов, ни идентификатор устройства. В запросе только адрес нужного файла и название приложения (`malchiki-vs-devochki`) в заголовке User-Agent: ни модели телефона, ни версии Android, ни номера сборки в нём нет.
- Как любой сайт, GitHub и jsDelivr видят IP-адрес, с которого пришёл запрос, и обычные технические данные запроса и обрабатывают их по своим правилам. Разработчик эти сведения не получает.
- Других разрешений приложение не запрашивает: ни к камере, микрофону, контактам, файлам, ни к местоположению.

## Что хранится на вашем телефоне

Только то, что нужно для игры, и всё это остаётся на вашем телефоне. Настройки и историю приложение хранит в закрытой области самого приложения, другие приложения этого не видят:

- настройки: включён ли таймер и сколько секунд на ответ;
- история показанных вопросов (идентификаторы вопросов и время показа) — чтобы вопросы не повторялись;
- скачанные наборы вопросов и фото к ним — чтобы играть с ними без интернета.

Названия команд и ход текущей партии приложение в свою область не записывает: их хранит сама система Android как сохранённое состояние экрана, пока приложение свёрнуто, чтобы партия не потерялась. Закрытая вами партия не сохраняется.

Названия команд вы вводите сами; они остаются в приложении и никуда не отправляются.

Резервное копирование Android для приложения отключено: эти данные не попадают ни в облачную копию, ни при переносе на другое устройство.

## Как удалить свои данные

- «Настройки» → «Сбросить историю вопросов» — удаляет историю показанных вопросов.
- Удаление приложения или «Очистить данные» в настройках Android — удаляет всё, что приложение хранило, в том числе скачанные наборы вопросов.

## Дети

Приложение рассчитано на взрослую компанию друзей. Оно не собирает данные ни о ком, в том числе о детях.

## Изменения политики

Если приложение когда-нибудь начнёт что-то собирать или выходить в сеть по другим поводам (например, появятся реклама или подписка), эта политика будет обновлена до выхода такой версии, а дата в начале документа изменится.
